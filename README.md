# Astro Launcher releases

Official binary release channel for [Astro Launcher](https://ae-storefront.vercel.app).

- Download the launcher from the **Latest** release.
- Anime Expeditions and Fisch are installed and updated through Astro Launcher.
- Every published asset is checked against the SHA-256 stored in the launcher catalog.

This repository contains compiled release assets only. Source code, credentials, signing keys, and customer data are not published here.
